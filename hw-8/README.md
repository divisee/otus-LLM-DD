# Домашнее задание "Извлечение сущностей и событий из набора текстов"

## Цель:
В этом ДЗ вы научитесь извлекать структурированную информацию (сущности, события и отношения) из текстов с помощью методов NER и Information Extraction. Вы примените локально развернутые языковые модели для решения реальных задач (юридические, медицинские, новостные данные), оптимизируете производительность моделей и разработаете простое приложение, демонстрирующее извлечение данных.

## Описание/Пошаговая инструкция выполнения домашнего задания:
Выберите один из трёх треков:

### 📚 Трек A: Извлечение из юридических документов.

Датасеты на выбор:

- https://huggingface.co/datasets/theatticusproject/cuad - 13,000+ размеченных коммерческих контрактов (41 категория) - ОСНОВНОЙ (рекомендуется 1K-2K примеров).
- https://huggingface.co/datasets/hugsid/legal-contracts - 38,000 контрактов разных типов (можно взять 500-1K примеров).
- https://huggingface.co/datasets/HFforLegal/case-law - судебные решения (для продвинутых, 200-500 примеров).
- Локальные модели: Llama-2-7B-Chat, Mistral-7B, Saiga-7B (русский).
- Извлекаемые сущности: PERSON, ORG, MONEY, DATE, CONTRACT_TYPE, OBLIGATION, JURISDICTION.

### 📰 Трек B: Извлечение из новостных диалогов.

Датасеты на выбор:

- https://huggingface.co/datasets/allenai/WildChat-1M - 1.04M реальных диалогов - ОСНОВНОЙ (рекомендуется отфильтровать 2K-5K новостных диалогов).
- https://huggingface.co/datasets/lmsys/lmsys-chat-1m - 1M диалогов с LLM (можно взять 1K-3K примеров).
- Локальные модели: Llama-2-7B, OpenChat-7B, Vicuna-7B
- Извлекаемые сущности: PERSON, ORG, LOC, EVENT, DATE, IMPACT, SOURCE

### 🩺 Трек C: Извлечение из медицинских диалогов.

Датасеты на выбор:

- https://huggingface.co/datasets/bigbio/meddialog - 260k диалогов врач-пациент - ОСНОВНОЙ (рекомендуется 3K-5K диалогов).
- https://huggingface.co/datasets/omi-health/medical-dialogue-to-soap-summary - 10k с SOAP резюме (можно использовать весь датасет).
- https://huggingface.co/datasets/UCSD26/medical_dialog - медицинские диалоги EN+CN (только английская часть, 1K-2K примеров).
- Локальные модели: BioMistral, Llama-2-7B-Chat, Mistral-7B-Instruct.
- Извлекаемые сущности: SYMPTOM, DIAGNOSIS, MEDICATION, DOSAGE, DURATION, SIDE_EFFECT.

## 💡 Рекомендации по размерам подвыборок:

- Для CPU обработки: 500-1K примеров.
- Для GPU обработки: 1K-5K примеров.
- Для demo целей: 100-200 примеров.

## Этапы выполнения:
- Локальное развертывание: Развернуть 2-3 модели локально, сравнить производительность quantized vs full precision.
- Подготовка данных: Загрузить выбранный датасет, создать подвыборку подходящего размера, настроить промпты для извлечения сущностей.
- Оптимизация для IE: Реализовать batch processing, оптимизировать inference одним из способов, измерить throughput на подвыборке.
- Анализ производительности: Сравнить скорость (tokens/sec), качество извлечения (precision/recall), потребление ресурсов (RAM/VRAM) разных моделей.

## Формат сдачи можно выбрать любой:
- Отдельный репозиторий с кодом на Github.
- Jupyter ноутбук с комментариями и примерами работы моделей.

## Критерии оценки:
Статус "Принято" состоит из следующих критериев:
- Локальное развертывание (35%): успешный запуск локальный моделей.
- Оптимизация производительности (30%): эффективный inference, batching, caching, измерение throughput и latency на выбранных подвыборках.
- Качество извлечения (25%): точность NER/IE на специализированном домене, обработка edge cases.
- Анализ и сравнение (10%): benchmark инференса, понимание trade-offs между скоростью и качеством.
- Бонусы (+5-15%): Streaming processing больших датасетов, custom quantization, parallel extraction.

## Компетенции:
- Разрабатывать, дообучать и оптимизировать LLM, расширяя их функциональность через Fine-tuning, вызов внешних функций, локальный запуск и извлечение информации из текста
- Извлекать данные из текста (NER, IE)
