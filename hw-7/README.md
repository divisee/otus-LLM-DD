# Домашнее задание "Дообучение модели под свою задачу и интеграция с внешними функциями"

## Цель:
- В этом ДЗ вы научитесь использовать техники параметрически-эффективного fine-tuning (LoRA, PEFT) для адаптации больших языковых моделей под конкретные задачи. Вы создадите интеграцию LLM с внешними API и функциями для расширения возможностей моделей.


## Описание/Пошаговая инструкция выполнения домашнего задания:
 Выберите один из трех треков (или придумайте свой):


### 💬 Трек A: Многоязычный диалоговый ассистент.
- Fine-tuning: Улучшение качества диалогов на разных языках, понимание контекста.
- Датасет: huggingface.co/datasets/OpenAssistant/oasst1 (84.4k диалогов, 35 языков).
- Примерные tools: translate_text, detect_language, get_time_zone, currency_converter.

### 🤖 Трек B: Продвинутый чат-ассистент.
- Fine-tuning: Качественные ответы в стиле популярных LLM, многоступенчатые рассуждения.
- Датасет: huggingface.co/datasets/lmsys/lmsys-chat-1m (1M реальных диалогов с 25 LLM).
- Примерные tools: web_search, calculator, code_executor, fact_checker.

### 📝 Трек C: Инструктивный помощник.
- Fine-tuning: Улучшение следования инструкциям, структурированные ответы.
- Датасет: huggingface.co/datasets/mlabonne/FineTome-100k (100k высококачественных инструкций).
- Примерные tools: text_formatter, template_generator, structure_analyzer, content_validator.

## Этапы выполнения:
- Fine-tuning для диалогов: Подготовить выбранный датасет, обучить модель LoRA, продемонстрировать улучшения в качестве диалогов.
- Создание LangChain Tools (или аналогичных в другом фреймворке): Написать 2-3 полезных инструмента с @tool (функции на выбор студента).
- Демонстрация интеграции: Показать как fine-tuned модель использует tools в реальных сценариях.

## Вспомогательные материалы:

## Критерии оценки:
### Статус "Принято" состоит из следующих критериев:

- Качество fine-tuning (50%): улучшение качества диалогов и следования инструкциям, корректность настройки LoRA, демонстрация прогресса обучения, анализ до/после.
- LangChain Tools реализация (30%): полезность и корректность tools, правильная интеграция с LangChain, демонстрация работы.
- Демонстрация сценариев (20%): реалистичные примеры использования модели + tools, качество интеграции, понимание возможностей и ограничений.
- Бонусы (+5-10%): реальные API в tools, многоступенчатое использование инструментов, креативные применения.
