# otus-LLM-DD

Репозиторий с домашними работами курса **LLM Driven Development «Разработка и эксплуатация AI»** (OTUS).  
Период обучения: **ноябрь 2025 — апрель 2026**.

## Домашние работы

1. **ДЗ-1: Визуализация механизма работы Attention**  
   Понять и проинтерпретировать self-attention в трансформерах: извлечение attention-весов, визуализация (heatmap), сравнение паттернов для разных архитектур (BERT vs GPT-2) и анализ multi-head внимания.  
   Ссылки: [`hw-1/`](hw-1/) · [`hw-1/README.md`](hw-1/README.md)

2. **ДЗ-2: Построение LLM-пайплайна (ER / tonality detection)**  
   Пройти полный цикл работы с данными для LLM: анализ «грязного» датасета, очистка/нормализация русскоязычных текстов, использование готовых моделей HuggingFace (sentiment/NER), разработка промптов (в т.ч. JSON-вывод) и сравнение итогов классического подхода vs LLM/API.  
   Ссылки: [`hw-2/`](hw-2/) · [`hw-2/README.md`](hw-2/README.md)

3. **ДЗ-3: Трекинг LLM-инференса с vLLM**  
   Развернуть локальный OpenAI-compatible сервер vLLM, вызывать модель через HTTP или OpenAI SDK и настроить оценку качества ответов через **MLflow** (в т.ч. подход LLM-as-a-Judge + кастомная GenAI-метрика).  
   Ссылки: [`hw-3/`](hw-3/) · [`hw-3/README.md`](hw-3/README.md)

4. **ДЗ-4: Оценка качества генерации текста с помощью метрик**  
   Выбрать трек (QA / summarization / classification), собрать датасет и сравнить 2–3 модели по метрикам: обязательные (semantic similarity, время генерации, длина ответа) и специализированные (F1/EM/ROUGE/BLEU/Accuracy и т.д.), провести эксперименты (zero-shot vs few-shot, влияние длины промпта/temperature) и оформить выводы.  
   Ссылки: [`hw-4/`](hw-4/) · [`hw-4/README.md`](hw-4/README.md)

5. **ДЗ-5: Собственное LLM-приложение + мониторинг через Langfuse**  
   Собрать простое LLM-приложение (например, RAG/суммаризатор/чат-бот) и инструментировать его через Langfuse: трассировка (traces/spans/generations), метрики/скоры, наблюдаемость, анализ качества и производительности.  
   Ссылки: [`hw-5/`](hw-5/) · [`hw-5/README.md`](hw-5/README.md)

6. **ДЗ-6: RAG-система с поиском по собственной базе документов**  
   Реализовать RAG end-to-end: выбрать векторную БД, подготовить данные и эмбеддинги, проиндексировать документы, настроить ANN-поиск (IVF/HNSW/и т.д.), сравнить trade-offs точность/скорость и (опционально) сделать hybrid search/батчинг.  
   Ссылки: [`hw-6/`](hw-6/) · [`hw-6/README.md`](hw-6/README.md)

7. **ДЗ-7: Дообучение модели под свою задачу и интеграция с внешними функциями**  
   Применить параметрически-эффективный fine-tuning (LoRA/PEFT) для адаптации LLM под конкретный трек (многоязычный ассистент / продвинутый чат / инструктивный помощник), написать 2–3 LangChain Tools и продемонстрировать интеграцию fine-tuned модели с внешними функциями.  
   Ссылки: [`hw-7/`](hw-7/) · [`hw-7/README.md`](hw-7/README.md)

8. **ДЗ-8: Извлечение сущностей и событий из набора текстов**  
   Извлечь структурированную информацию (NER/IE) из текстов выбранного домена (юридические документы / новостные диалоги / медицинские диалоги) с помощью локально развёрнутых LLM, оптимизировать inference (batching, quantization) и сравнить модели по скорости и качеству.  
   Ссылки: [`hw-8/`](hw-8/) · [`hw-8/README.md`](hw-8/README.md)

9. **ДЗ-9: CI/CD пайплайн с автотестами и проверкой на галлюцинации**  
   Создать LLM-приложение, подготовить золотые примеры, настроить тестирование с Ragas (Faithfulness, Answer Relevance, Context Recall), обернуть метрики в pytest с пороговыми значениями и интегрировать в CI/CD через GitHub Actions с quality gates.  
   Ссылки: [`hw-9/`](hw-9/) · [`hw-9/README.md`](hw-9/README.md)

10. **ДЗ-10: Мультимодальный поиск — от текста к изображению / звуку**  
    Построить систему мультимодального поиска изображений/аудио по текстовым запросам: создать мультимодальные эмбеддинги (CLIP), построить индекс в векторной БД, реализовать ранжирование результатов и сравнить разные модели по метрикам качества и скорости.  
    Ссылки: [`hw-10/`](hw-10/) · [`hw-10/README.md`](hw-10/README.md)
