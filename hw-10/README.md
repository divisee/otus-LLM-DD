# Домашнее задание "Мультимодальный поиск: от текста к изображению / звуку"

## Цель:
В этом ДЗ вы научитесь строить системы мультимодального поиска, способные искать изображения или аудио по текстовым запросам. Вы создадите мультимодальные эмбеддинги, построите индекс на основе векторных БД и реализуете поиск, оптимизируя точность и скорость ответов на запросы.

## Описание/Пошаговая инструкция выполнения домашнего задания:
Выберите один из трех треков:

### 🖼️ Трек A. Поиск изображений по тексту.

Датасеты на выбор:

- https://huggingface.co/datasets/google-research-datasets/conceptual_captions — 3.3M изображений с подписями (можно взять 10K-50K примеров).
- https://huggingface.co/datasets/laion/laion2B-en — 2.3B изображений с текстом (рекомендуется streaming режим, 5K-20K примеров).
- https://huggingface.co/datasets/ranjaykrishna/visual_genome — 108K изображений с аннотациями (полный датасет или подвыборка).
- Модели: CLIP (`openai/clip-vit-base-patch32`), SentenceTransformers (`all-MiniLM-L6-v2`).
- Примерные запросы: "собака на пляже", "красный автомобиль", "люди играют в футбол".

## Этапы выполнения:
- **Подготовка данных:** Загрузить датасет, подготовить изображения/аудио, создать мультимодальные эмбеддинги.
- **Создание индекса:** Построить векторную БД (на ваш выбор), проиндексировать контент по эмбеддингам.
- **Реализация поиска:** Создать систему поиска, реализовать ранжирование результатов, оптимизировать запросы.
- **Оценка и анализ:** Создать тестовые запросы, измерить точность поиска, сравнить разные модели.

## Критерии оценки:
Статус "Принято" состоит из следующих критериев:
- **Техническая реализация (40%):** корректность создания эмбеддингов, эффективность индексации, качество функций поиска.
- **Качество поиска (30%):** релевантность результатов, скорость поиска, обработка сложных запросов.
- **Анализ и эксперименты (20%):** сравнение разных моделей, метрики качества, интерпретация результатов.
- **Документация (10%):** понятность кода, полнота отчета, качество визуализации результатов.

- Работать с мультимодальными моделями, разработкой приложений с текстом, изображениями и другими данными
- Использовать методы интеграции мультимодальных данных, примеры использования в AI-приложениях
