# Домашнее задание "Оценка качества генерации текста с помощью метрик"

## Цель:
В этом ДЗ вы научитесь практически применять метрики оценки качества для сравнения языковых моделей и интерпретировать результаты для принятия обоснованных решений.


## Описание/Пошаговая инструкция выполнения домашнего задания:
Выберите трек (достаточно будет выбрать один из трёх, но можно и все сразу).


### 🔸 Трек A: Question Answering (QA).

Задача: Оценка качества ответов на вопросы.

Датасет: 50-100 вопросов на русском языке с эталонными ответами.

Метрики: F1-score, Exact Match, Semantic Similarity, BLEU.

Особенности: Фокус на точности фактической информации.


📊 Примеры датасетов:

Готовые публичные датасеты:

SberQuAD - русская версия SQuAD (контекст + вопрос + ответ).

Источник: Hugging Face sberbank-ai/sberquad.

Размер: 50K+ примеров.

RuCoQA - разговорные QA на русском.

Источник: GitHub sberbank-ai/ru-coqa

RUREBUS - загадки и головоломки на русском.

Источник: Hugging Face ai-forever/RUREBUS

MuSeRC - множественный выбор на русском.

Источник: Russian SuperGLUE


Варианты создания собственного датасета:

Академический: Вопросы по лекциям курса LLM.
Новостной: QA по статьям РБК/Коммерсанта.
Специализированный: IT-термины, медицина, право.
Фактологический: Вопросы о российской истории/географии.

### 🔸 Трек B: Text Summarization.

Задача: Оценка качества реферирования текстов.

Датасет: 30-50 текстов для реферирования с эталонными саммари.

Метрики: ROUGE-1, ROUGE-L, BLEU, Semantic Similarity.

Особенности: Фокус на сохранении ключевой информации.


📊 Примеры датасетов:

Готовые публичные датасеты:

Gazeta - новостные статьи с заголовками.

Источник: Hugging Face IlyaGusev/gazeta

Размер: 63K статей.

RuSumm - русские тексты для суммаризации.

Источник: GitHub RussianNLP/RuSumm

XL-Sum Russian - мультиязычная суммаризация.

Источник: Hugging Face csebuetnlp/xlsum

RIA News - новости РИА с краткими описаниями.

Источник: Kaggle


Варианты создания собственного датасета:

Научные статьи: Аннотации к статьям с arXiv (переведенные)
Корпоративные документы: Отчёты компаний + executive summary
Блоги и статьи: Посты на Хабре с краткими описаниями
Юридические тексты: Законы + краткие выжимки
Книжные аннотации: Описания книг + их краткие пересказы

### 🔸 Трек C: Text Classification & Sentiment Analysis.

Задача: Оценка качества классификации и анализа тональности.

Датасет: 100-200 текстов (отзывы, новости, посты) с разметкой классов/тональности.

Метрики: Accuracy, Precision, Recall, F1-score, Confusion Matrix.

Особенности: Фокус на понимании и классификации текста.

## Часть 1. Подготовка:
Выбрать трек и обосновать выбор (2-3 предложения).
Выбрать 2-3 языковые модели для сравнения (например: GPT-3.5-turbo, Claude-3-haiku, ruGPT-3).

Подготовить датасет согласно выбранному треку:
- Можно использовать готовые датасеты (см. примеры выше).
- Или создать собственный тематический датасет.
- Указать источник и краткое описание данных.

## Часть 2. Реализация метрик:
Обязательные метрики для всех треков:
- Semantic Similarity.
- Время генерации ответа.
- Длина сгенерированного текста.
- Специализированные метрики по трекам:


- Трек A (QA): F1-score, Exact Match, BLEU
- Трек B (Summarization): ROUGE-1, ROUGE-L, BLEU
- Трек C (Classification): Accuracy, Precision, Recall, F1-score, Confusion Matrix

## Часть 3. Эксперименты:
- Протестировать модели на подготовленном датасете.
- Влияние длины промпта на качество.
- Сравнение zero-shot vs few-shot промптинга.
- Анализ типичных ошибок моделей.
- A/B-тестирование разных форматов промптов.
- Анализ влияния температуры генерации.


## Часть 4. Анализ и выводы. Отчет (2-3 страницы):
- Сравнительная таблица результатов по метрикам.
- Качественный анализ примеров (5-10 лучших/худших результатов).
- Рекомендации по выбору модели для выбранной задачи.
- Критический анализ метрик - какие метрики оказались наиболее/наименее информативными.
