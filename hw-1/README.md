# Домашнее задание "Визуализация механизма работы Attention"

## Цель:
В этом ДЗ вы научитесь визуализировать и анализировать работу механизмов Attention в современных трансформерах, сравнивать различные архитектуры (BERT, GPT-2), понимать специализацию Attention голов и интерпретировать поведение моделей.

## Описание/Пошаговая инструкция выполнения домашнего задания:
### Подготовка окружения и моделей
- Установите необходимые библиотеки (transformers, torch, matplotlib, seaborn, bertviz)
- Загрузите и настройте модели BERT и GPT-2 с выводом attention весов
- Подготовьте тестовый текст для анализа

### Получение и визуализация attention
- Реализуйте функцию для извлечения attention весов из моделей
- Создайте базовую heatmap визуализацию attention матриц
- Сравните attention patterns между BERT и GPT-2 для одного текста

### Анализ различий архитектур
- Проанализируйте различия в attention patterns между BERT (bidirectional) и GPT-2 (causal)
- Исследуйте изменения attention весов в разных слоях сети

## Часть 2. Дополнительные задания (30% оценки):

### Multi-Head Attention анализ
- Визуализируйте attention для всех голов в выбранном слое
- Проанализируйте специализацию разных attention голов

### Кросс-языковое исследование
- Загрузите русскоязычную модель (например, RuBERT)
- Проанализируйте attention patterns для русского текста
- Сравните особенности attention в разноязычных моделях

## Итоговый анализ
- Сделайте выводы о практическом применении полученных знаний
- Опишите, как визуализация attention помогает в отладке моделей

## Формат сдачи
Jupyter Notebook (.ipynb файл) содержащий:
- Рабочий код со всеми выполненными заданиями
- Визуализации - attention heatmaps, графики, диаграммы
- Аналитические выводы - ответы на вопросы и интерпретация результатов
- Документацию - комментарии к коду и объяснение методов

Статус "Принято" состоит из следующих критериев:

1. Техническая реализация (40%):

- Качество реализации функций визуализации.
- Работоспособность всего кода.
2. Качество визуализации (30%):

3. Анализ и выводы (30%):
- Качество ответов на аналитические вопросы.
- Понимание различий между архитектурами.
