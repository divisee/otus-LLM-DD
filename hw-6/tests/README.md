# Тесты RAG-пайплайна

Этот каталог содержит скрипт для автоматического тестирования RAG-пайплайна Movie Agent.

## Запуск тестов

```bash
cd hw-5-6/tests
python run_tests.py
```

## Что делает скрипт

- Запускает 5 тестовых запросов к пайплайну
- Каждый тест проверяет работу RAG, веб-поиска или комбинированного режима
- Результаты сохраняются в JSON-файл с timestamp (например, `results_20260201_120000.json`)
- Выводит итоги: сколько тестов прошло успешно, сколько провалилось

## Примеры тестов

1. **RAG: Фильм про мальчика с волшебными силами** - поиск в локальной базе
2. **RAG: Фильм про ограбление казино** - поиск по сюжету
3. **WEB: Топ комедий 2025** - рекомендации через веб-поиск
4. **WEB: Фильмы для семейного просмотра** - подборка через веб
5. **MIXED: Драмы про семью** - комбинированный запрос

## Формат результатов

Результаты сохраняются в JSON с полями:
- `timestamp`: время запуска
- `tests_count`: общее количество тестов
- `passed`: количество успешных
- `failed`: количество проваленных
- `results`: массив с деталями каждого теста (stdout, stderr, returncode)

## Требования

- Все компоненты пайплайна должны быть запущены (Qdrant, Ollama, Langfuse)
- Файл `config.yaml` должен быть настроен с API-ключами
- Данные должны быть загружены в Qdrant (`python scripts/ingest_movies.py`)
